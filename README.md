# Gestor de Contratos Universitarios

Sistema universitario de automatización de documentos de contratación.

## Requisitos

- Python 3.14
- [uv](https://docs.astral.sh/uv/)

## Instalación

```bash
uv sync
```

## Ejecutar la aplicación

```bash
uv run streamlit run app.py
```

## Verificaciones

```bash
uv run pytest
uv run ruff check .
```
